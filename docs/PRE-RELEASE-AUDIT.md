# Pre-release deep audit — 2026-07-05

**Метод:** 12 фінд-агентів (усі 4 ролі + наскрізні journeys + DB-контракт + релізна готовність) → семантична дедуплікація → адверсарна верифікація кожної HIGH/MED знахідки. 69 сирих → 11 підтверджених (3 HIGH + 8 MED) + 12 LOW. 0 спростованих.

**Виправлено:** усе, крім однієї косметичної LOW (нижче). Коміти `9c0affa`, `cfb5272`, `37cc0bd`, `73b3c8e`.

## HIGH (виправлено)
1. **Груповий урок = фейковий борг** (`FinancesPage`/`financials.ts`). Майбутні заплановані групові уроки рахувались як борг (синтетичний `tutor_payout_status='paid'` проходив предикат білабельності) — Фінанси показували борг за уроки, яких ще не було, і суперечили дашборду. Додано прапорець `is_group`, закрито тестами.
2. **«Закрити день» ламав групові оплати** (`DashboardPage`/`CloseDayDialog`). Позначка «оплачено» для групового уроку писалась у `lesson_details` (не та таблиця), «успішно» — а всі учасники лишались неоплаченими. Групові уроки тепер закривають лише статус.
3. **Менеджер не міг написати учневі без чату** (`ReferralsPage`/`ChatsPage`). Кнопка «Написати» на /referrals вела в глухий кут для учня-самореєстранта (найважливіша аудиторія). Тепер створюється чат-тред менеджера.

## MED (виправлено)
- **Картка прибутку** рахувала «vs минулий місяць» і 6-міс. стовпчики з 30-денного вікна → фейково занижені. Додано окреме 6-місячне грошове вікно.
- **«До виплати від хабу»** і **день виплат** рахували майбутні непроведені уроки. Тепер спільний предикат білабельності + міграція `20260722000000` (RPC платить лише проведені).
- **Кнопка «Нагадати»** в банері боргів фейл-ілась на вкладці «Дохід» (брала дані активної вкладки). Тепер бере всі несплачені.
- **CSV-експорт** вигадував групові гроші (повна ціна як прибуток). Тепер «—» як на екрані.
- **Кокпіт незалежного репетитора** не мав FAB «Записати оплату» — головна дія була недосяжна. Додано FAB + шит.
- **«Нагадати» pending-репетитору** слало student-invite з посиланням `role=student`. Тепер лише для учнів.
- **«Гаманець» мульти-репетиторного учня** мовчки відкривав першого репетитора → поповнення не тому. Тепер кнопка гаманця в кожному рядку ставки + ім'я репетитора в шапці діалогу.
