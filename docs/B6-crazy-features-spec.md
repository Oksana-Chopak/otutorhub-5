# B6 · Крейзі-фічі: специфікація (затверджено)

Статус позначок: ✅ зроблено в клієнті · 🔌 потребує серверного шматка (edge function / scheduler), який деплоїться на Supabase власницею.

## 1. 🧠 «Памʼять учня»
- ✅ **Lite (в проді):** у воркспейсі уроку репетитор бачить картку «Минулий урок · {дата}» з конспектом і домашкою попереднього завершеного уроку пари (LessonWorkspace, indigo-картка над приватними нотатками).
- 🔌 **Full:** edge function `student-memory-brief`:
  - вхід: `{ tutor_id, student_id }`;
  - читає останні 5 `lesson_details.summary` пари + `tutor_student_notes.notes`;
  - промпт: «Стисни в 3 пункти: що повторити, де учень плутався, з чого почати урок»;
  - вихід кешувати в `lesson_details.ai_brief` поточного уроку (text). Клієнт уже має місце для рендеру — та сама картка 🧠 (додати кнопку «Підказка AI»).

## 2. ✍️ Створення уроків текстом («напиши як людина»)
- 🔌 Edge function `parse-lessons-text`:
  - вхід: `{ text: "Аня пн і чт 18:00 по 60хв 500грн", tutor_tz }`;
  - системний промпт повертає СТРОГО JSON: `[{ student_name, weekday[], time, duration_minutes, price?, start_date? }]`;
  - клієнт мапить `student_name` на існуючих учнів (fuzzy по first/last), невідомих пропонує створити;
  - вставка уроків = той самий код серії з QuickLessonDialog (вже вміє пакети по тижнях).
- Клієнтська точка входу: поле «✨ Опиши розклад словами» в QuickLessonDialog під час порожнього стану / окремий пункт FAB.

## 3. 📸 Імпорт розкладу зі скріншота/фото зошита
- 🔌 Те саме, що №2, але вхід — зображення (base64) у ту ж функцію (vision-модель), той самий JSON-контракт. Окремої клієнтської логіки майже не треба: переюз мапінгу з №2.

## 4. 📦 Передплачені пакети уроків
- **Ядро вже існує:** гаманець (`student_wallet_transactions`, RPC `wallet_topup`, `RecordPaymentSheet` → вкладка «Передоплата», списання при проведенні).
- Що додати (клієнт, без міграцій):
  - учневі в `StudentPaymentsPage` — картка балансу «Передплачено: N уроків» (читає баланс гаманця пари);
  - репетитору на картці учня (MyStudents) — бейдж залишку пакета;
  - у CloseDayDialog: якщо в пари є баланс — авто-вмикати «₴» з підписом «з пакета».
- 🔌 Опційно: LiqPay-лінк «купити пакет 8 уроків −10%» — потребує бекенд-вебхука оплати.

## 5. Авто-нагадування про борг (з B3)
- Клієнт уже зберігає режим/дні в правилах (`ProRulesCard`) і має ручне «Нагадати» (insertNotification).
- 🔌 Scheduler (cron edge function `debt-reminders`, щодня 10:00 Києва): для кожного репетитора з увімкненим режимом — знайти неоплачені уроки старші за N днів → insertNotification учню + (опц.) Telegram. Дедуп: тип `payment_reminder_auto_{lesson_id}_{yyyy-mm-dd}`.

## 6. AI-конспект: серверні хвости (з раніше)
- 🔌 Scheduler `fireflies-auto-join`: на час уроку, якщо `tutor_workspace_settings.ai_notes_auto` і є meeting_url → викликати `fireflies-start-recording` (клієнтський авто-старт при кліку вже працює).
- 🔌 Вебхук Fireflies «transcription complete»: якщо `ai_notes_auto_send` → записати конспект у `lesson_details.summary` + insertNotification учню.
