## 🟢 КРОК 2 — Android (простіший, почни з нього)
Тобі потрібен компʼютер з безкоштовним **Android Studio**.
1. Завантаж проєкт собі: у терміналі `git clone <твій репозиторій>`, далі `npm install`.
2. Запусти: `npm run cap:android` — відкриється Android Studio.
3. Меню **Build → Generate Signed Bundle / APK → Android App Bundle**.
4. Створи «keystore» (ключ підпису) і **збережи його дуже надійно** (без нього не зможеш оновлювати застосунок!).
5. На play.google.com/console → твій застосунок → **Internal testing** → завантаж файл `.aab`.
6. Заповни анкету **Data safety** — готові відповіді в `APP-REVIEW-NOTES.md` (внизу).
7. Перевір на своєму телефоні → потім **Production**.

## 🟢 КРОК 3 — iPhone (потрібен Mac)
Потрібен компʼютер Apple (Mac) з безкоштовним **Xcode**.
1. На Mac: `npx cap add ios`, потім `npm run cap:sync`, потім `npx cap open ios`.
2. У Xcode підпиши застосунок своїм Apple Developer акаунтом.
3. На appstoreconnect.apple.com → **+ New App**.
4. App Privacy анкета — готові відповіді в `APP-REVIEW-NOTES.md`.
5. У полі App Review Notes встав текст з `APP-REVIEW-NOTES.md` + **створи демо-акаунт** з прикладами даних і дай його логін/пароль.
6. TestFlight → перевір на телефоні → Submit.
