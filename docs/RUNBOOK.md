# RUNBOOK oTutorHub — операційка власниці (CTO, 11.08.2026)

## Щоденний моніторинг — сам приходить до тебе
- **Ранковий телеграм-дайджест (менеджер):** уроки дня · «💳 Борг учнів» ·
  «👛 До виплати репетиторам» · «🛠 Технічні помилки за добу: N» (якщо N>0 —
  відкрий /errors і скопіюй верхній запис Клоду).
- **Картка «Заборгованості» (Фінанси):** під нею рядок самозвірки.
  «✓» — все зійшлося з базою; жовтий «⚠️ Розбіжність…» — скопіюй рядок Клоду.

## Куди дивитись при інциденті
1. **/errors** — реальні помилки застосунку (шум розширень відфільтровано).
2. **Supabase → Edge Functions → Logs** — падіння функцій (оплати/дайджест/пошта).
3. **CHECK-EMAILS.sql** (outputs) — статуси листів, якщо «не приходить пошта».
4. **PARITY-DEBTS.sql** — ручна звірка боргів (не обовʼязкова: є самозвірка).

## Реліз у Google Play — правило безпечного розкату
Production → після ревʼю обирай **поетапний розкат 20%** → доба без нових
помилок у дайджесті → підвищ до 100% тим самим екраном.

## Ротації секретів (виконати ОДРАЗУ після виходу релізу)
- [ ] Пароль keystore (Fedor1_Nazar2 світився в чатах): keytool -storepasswd …
      (Клод дасть однорядник і оновить інструкцію збірки).
- [ ] GitHub PAT: Settings → Developer settings → знайти токен → Regenerate;
      новий надіслати Клоду В НОВОМУ чаті одним повідомленням.
- [ ] Перевірити Supabase → Settings → Backups: щоденні бекапи/PITR увімкнені
      відповідно до плану проєкту (одна галочка очима).
